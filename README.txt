# AUREVALD — Crack Intro
GitHub Pages용 단일 페이지 소개 사이트입니다.

## 이미지 넣기
1. `images` 폴더에 캐릭터 이미지를 넣습니다.
2. `index.html`에서 해당 placeholder를 `<img src="images/cassian.jpg">` 형태로 교체하면 됩니다.
3. 캐릭터별 이미지 파일명은 cassian.jpg / edwin.jpg / adeline.jpg / rowen.jpg처럼 맞추면 편합니다.

현재 버전은 이미지가 없어도 디자인을 확인할 수 있도록 북부 성/초상 영역을 그래픽 placeholder로 구성했습니다.
